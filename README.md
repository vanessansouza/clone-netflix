* CSS3

* GitHub Pages

* Layout structure and grid arrangement
* CSS positioning and responsive design
* Card styling and hover effects
* Adapting entertainment platform UI elements

### 🇧🇷 Português
Interface de clone de catálogo da Netflix desenvolvida utilizando Inteligência Artificial por meio de comandos (*prompts*) com o GitHub Copilot no VS Code, com o objetivo de explorar e replicar layouts de plataformas de streaming, estruturas em grade e o design de cartões interativos usando HTML5 e CSS3.

🛠️ **Tecnologias**
* HTML5
* CSS3
* GitHub Copilot (VS Code)
* Git & GitHub
* GitHub Pages

💡 **Conceitos Praticados**
* Engenharia de prompts e desenvolvimento assistido por IA no VS Code
* Estruturação de layout e organização em grade (*Grid*)
* Posicionamento com CSS e design responsivo
* Estilização de cartões (*cards*) e efeitos visuais ao passar o mouse (*hover*)
* Adaptação de elementos de interface de plataformas de streaming
